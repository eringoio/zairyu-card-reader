# リリース作成

[English →](releasing.md)

この文書は、Windows向けの公開リリースを準備する保守担当者向けです。

## ビルド前

1. 確認済みのクリーンなコミットから始め、[CHANGELOG.md](../CHANGELOG.md)を更新します。
2. 対応するWindows環境で完全なテストスイートとリリースチェックを実行します。
3. 同梱するOCRモデルと信頼アンカーを確認します。
4. [RELEASE_CHECKLIST.ja.md](../RELEASE_CHECKLIST.ja.md)を確認し、リリースで使用した
   Windowsのバージョン、リーダー型番、ドライバーのバージョン、実在カードでの確認内容を記録します。

## ビルドと検査

リポジトリに記載されたビルドスクリプトでWindowsパッケージを作成します。公開前に配布物を検査し、
アプリ、必要なOCRモデル、意図した実行時ファイルだけが含まれていることを確認してください。
新しく展開したアーカイブをWindows PCでテストします。

## 未署名リリース

現在、このプロジェクトは未署名のWindowsビルドを公開します。WindowsでSmartScreenまたは発行元の
警告が表示される場合があります。利用者に警告を無条件で無視するよう案内してはいけません。
各アーカイブとともにSHA-256チェックサムを公開し、実行前に公式リリースから入手したことと
チェックサムを確認するよう案内してください。

## 公開

確認済みのタグからGitHubリリースを作成します。ZIPアーカイブとSHA-256チェックサムを添付します。
署名の有無、既知の制限を明記し、インストール、プライバシー、セキュリティ、トラブルシューティング
の文書へリンクしてください。カード情報、個人情報を含むスクリーンショット、秘密鍵、未公開の
テスト資料を公開してはいけません。
