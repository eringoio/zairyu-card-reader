# プライバシーとセキュリティ

[English →](privacy-and-security.md)

zairyu-card-reader は非常に重要な個人情報を扱います。カードの読み取りをローカルPC内で完結
させる設計ですが、ローカル専用のソフトウェアにもセキュリティ上の不具合が生じる可能性はあります。
Windows、カードリーダーのドライバー、本アプリを最新の状態に保ち、信頼できるPCでのみ利用してください。

## データの取扱い

- カードの読み取り、OCR、署名検証はローカルPCで実行されます。
- カード情報をサーバーへ送信せず、カードを読むためにインターネット接続は必要ありません。
- アカウント、クラウド保存、テレメトリ、アクセス解析、データベースはありません。
- カード画像、顔写真、ICチップの生データ、OCRデータをログに残しません。
- 保存される設定は、選択したリーダー番号のみです。

## ローカルサービスの境界

デスクトップアプリは、画面と同梱サービスの間でローカルのループバック接続を使用します。
ループバック以外からの接続は拒否され、LAN、トンネル、リバースプロキシ、公開サーバーでの利用を
想定していません。ローカルのポートを他の端末やネットワークに公開しないでください。

## 利用者の責任

カード所持者の情報を取り扱う権限がある場合にのみ利用してください。特にOCRで得た文字列は、
手続に使う前に画面の表示を確認してください。アプリを開いている間は、Windowsアカウントと画面を
第三者に見られないよう保護してください。

## セキュリティ報告

脆弱性の可能性を見つけた場合は、[SECURITY.ja.md](../SECURITY.ja.md)の手順で非公開に報告してください。
報告には実在のカード番号、画像、その他の個人情報を含めないでください。
