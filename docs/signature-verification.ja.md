# 署名検証

[English →](signature-verification.md)

対応しているカードデータについて、アプリは同梱の出入国在留管理庁の信頼アンカーを用いて
電子署名を検証できます。検証はすべてローカルPCで行われます。

## 結果の意味

成功は、利用できる署名対象データと証明書チェーンが、選択された信頼プロファイルに対して
検証できたことを意味します。対応項目として表示されたデータが、署名後に改ざんされていない
ことを示す有用な根拠になります。

ただし、カードが現在有効であること、提示者本人のカードであること、紛失・失効していないこと、
または特定の手続で有効であることを証明するものではありません。手続のルールに従い、現物の
カードも確認してください。

## 信頼プロファイル

通常のカードには本番プロファイルを使用します。テストプロファイルは、権限のあるテスト用資料
のためのものであり、実在カードの判断には使用しないでください。アプリは使用したプロファイルを
表示します。

## 制限

署名検証は、アプリが実装しているカード世代と項目に限って利用できます。「利用不可」「不完全」
「失敗」などの結果は、目視確認の代わりにはなりません。サポートを受ける際にもカード情報を
共有しないでください。

信頼アンカーはオフライン利用のために同梱されています。入手元と保守方針は
[公的証明書](official-certificates.ja.md)をご覧ください。
