# Release verification record — 0.2.1

Status: release candidate; this release is intentionally unsigned and publication is still
pending.

## Reported field-test environment

| Item | Recorded result |
|---|---|
| Reader | Sony FeliCa RC-S300 |
| Operating systems | Windows 10, Windows 11, Windows Server 2016 |
| Newer-generation residence cards | More than 60 tested |
| Older-generation residence cards | About 10 tested |
| Reader driver version | Not recorded |
| Exact Windows builds and display shell | Not recorded |

The maintainer reports that the application worked in these environments. This record does
not claim compatibility with every PC/SC reader, driver version, card condition, or Windows
configuration.

## Observed OCR behaviour

OCR worked well in most reported tests. Staff must nevertheless review every OCR-derived
name and address against the physical card:

- spaces in names can appear in the wrong places;
- part of a long name can be missing;
- addresses generally work well, but the final line after the prefecture and municipality
  can be read incorrectly;
- place names containing complex kanji can be misread.

## Known implementation limitation

Residence-status (在留資格) display mapping is not fully implemented. Confirm the displayed
status against the physical card.
