# トラブルシューティング

[English →](troubleshooting.md)

## リーダーが一覧に表示されない

1. リーダーをPCへ直接つなぎ直し、別のUSBポートも試してください。
2. メーカーが提供するWindowsドライバーをインストールまたは更新してください。
3. リーダーを使用している可能性のある他のソフトを終了し、本アプリを再起動してください。
4. WindowsでPC/SCスマートカードサービスが利用できることを確認してください。

本アプリは、Sony FeliCa RC-S300 と Windows 10、Windows 11、Windows Server 2016 で
実機確認を行いました。他のPC/SCリーダーでも動作する場合がありますが、保証はありません。

## カードを検出できない、または読み取れない

カードをいったん外してから再度リーダーに置き、動かさないでください。カード表面の番号を
正確に入力してください。カード世代やリーダー・ドライバーの組合せが未対応である可能性も
あります。サポート依頼に実在のカード番号やカード画像を掲載しないでください。

## OCRの結果が誤っている、または表示されない

OCRは、長い氏名、空白、複雑な漢字、住所の末尾部分で誤ることがあります。必ず目視で確認して
ください。既知の制限は[OCR](ocr.ja.md)をご覧ください。ソースビルドでOCRを利用できない場合は、
[ビルド](building.ja.md)の手順を確認してから再ビルドしてください。

## 署名検証が成功しない

まずカードを正常に読み取れていることを確認してください。「失敗」「不完全」「利用不可」の結果
だけでは原因は特定できず、カードが無効であることも示しません。現物のカードを確認し、手続の
ルールに従ってください。詳細は[署名検証](signature-verification.ja.md)をご覧ください。

## アプリの画面が開かない

ZIPファイルの中からではなく、展開した配布版を通常のローカルフォルダーで実行してください。
未署名の配布版ではWindowsの警告が表示される場合があります。実行を選択する前に、公式リリース
ページから入手したことと、公開されているSHA-256チェックサムが一致することを確認してください。

## 問題を報告する場合

アプリのバージョン、Windowsのバージョン、リーダーの型番、ドライバーのバージョン、個人情報を
含まない症状の説明を記載してください。カード所持者のデータ、画像、個人情報を含むスクリーン
ショット、同様のログ、カードの生通信データは含めないでください。
