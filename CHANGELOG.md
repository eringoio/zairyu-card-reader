# Changelog

All notable changes to this project are documented in this file.

## 0.2.1 — Initial public release

First public release of zairyu-card-reader.

- Reads compatible Japanese residence cards locally through a supported PC/SC reader.
- Provides card-data display, image OCR and signature-verification features.
- Includes English and Japanese user documentation.
- Does not upload card data or require an internet connection to read a card.

See [README.md](README.md) for installation, privacy and security information.
