# zairyu-card-reader（在留カードリーダー）

**[English README →](README.md)**

Windows PC と USB NFC リーダーを使い、在留カードを**そのPCの中だけで**読み取るスタンドアロン
ツールです。担当者が17項目を確認したうえで、固定の日本語タブ区切りテキストとしてコピーできます。

すべての処理は目の前のPCで完結します。サーバー、アカウント、クラウドはありません。カードの
読み取り中にネットワーク通信は一切発生しません。

> **本プロジェクトは独自に開発されたものであり、出入国在留管理庁または法務省が開発、承認、
> 推奨、認証しているものではありません。**

---

## できること

- PC に接続された PC/SC カードリーダーを検出します。
- リーダー上にカードがあるかを確認します。
- カード表面に印字された在留カード番号を入力したうえで、ICチップ内の構造化項目を読み取ります。
- 氏名・住所が画像として保存されている世代のカードでは、ローカルのOCRエンジンで読み取ります。
- 同梱されたオフラインの出入国在留管理庁証明書を用いて、電子署名を検証します。
- 確認用の17項目を画面に表示します。
- 1件、または画面内の一時リストにまとめた複数件を、固定の日本語タブ区切りテキストとして
  コピーします。

## できないこと・行わないこと

- **クラウド送信、テレメトリ、アクセス解析、自動更新、遠隔送信は一切ありません。**
- **データベースはありません。** 保存されるのは選択したリーダー番号だけです。
- **顔写真、カード画像、ICチップの生データ（APDU/TLV）** を保存・表示・記録・コピー・
  ディスク書き込みすることはありません。
- **マイナンバーおよびJPKIのデータは読み取りません。**
- 一括スキャン、担当者アカウント、集計機能はありません。
- **LAN・トンネル・リバースプロキシ・公開サーバーでの公開はできません。** サーバーは
  ループバック以外へのバインドを拒否します。

## 実機での確認状況

> 開発者は、60枚を超える実在の在留カードを使用して動作確認を行っています。その確認では、
> ICチップに保存された構造化項目の読み取りと電子署名の検証が正常に動作しました。ただし、
> カードの世代や状態、ICカードリーダー、ドライバー、OS、OCR環境などによって結果が異なる
> 可能性があります。

自動テストは合成データのみを使用しています。お使いの環境でのリーダー互換性、ドライバーの挙動、
Windows Server 2016 での動作、OCRの精度を保証するものではありません。

## OCRは完全ではありません。必ず目視で確認してください

氏名や住所が文字ではなく画像として保存されているカードでは、その値はローカルOCRによる
読み取り結果です。**コピーする前に、必ず手元のカードと照合してください。** 既知の問題には
次のものがあります。

- 氏名の途中に誤った位置でスペースが入る;
- 長い氏名の一部が欠ける;
- 氏名の文字が抜ける、または誤認識される;
- 住所の区切りが誤る;
- 住所の文字が抜ける、または誤認識される。

本プロジェクトはOCRの完全な精度を主張しません。

本アプリには**氏名や住所を入力する欄はありません**。入力するのは在留カード番号のみです。
OCRが何も読み取れなかった場合、その項目は「読み取れませんでした」と表示されます。値の修正は、
貼り付け先のシステムで行ってください。

詳細は [docs/ocr.md](docs/ocr.md)（英語）をご覧ください。

## 署名検証で確認できること・できないこと

> 署名検証は、ICチップから読み取ったデータと、対応する信頼情報との間の暗号学的な整合性を
> 確認するものです。それ自体は、そのカードが現在も有効であること、またはその後に失効して
> いないことを確認するものではありません。

検証はすべてオフラインで行われ、アプリに同梱された証明書を使用します。各証明書は使用前に
記録済みのSHA-256フィンガープリントと照合されます。既定は `production` プロファイルです。
公的テストカード用の証明書は `VERIFICATION_TRUST_PROFILE=official_test` によってのみ選択でき、
その場合は画面に警告が常時表示され、結果は「公的テストカードとして確認済み」にしかなりません。
本番カードの真正性確認結果になることは決してありません。

詳細は [docs/signature-verification.md](docs/signature-verification.md) および
[docs/official-certificates.md](docs/official-certificates.md)（英語）をご覧ください。

## 対応範囲外

個別の検討を経ていない限り、本アプリは以下に対応しません。

- マイナンバー機能を持つ特定在留カード;
- マイナンバーのアプリケーションデータ;
- JPKI;
- 特定在留カード用のRSA配送鍵（本リポジトリには一切含まれていません）;
- 遠隔・ネットワーク経由でのリーダー操作。

カード種別 `07` および `08` は、マイナンバーやJPKIへのアクセスを試みることなく、
ポリシーにより拒否されます。

## 動作要件

| 項目 | 要件 |
|---|---|
| OS | Windows 10 または 11（64ビット）。Windows Server 2016 はデスクトップ エクスペリエンス環境で、Chromium アプリモードにより対応します。 |
| リーダー | **ISO/IEC 14443 Type B** に対応した PC/SC 非接触リーダー。接触式のみ、または FeliCa / Type A のみのリーダーでは動作しません。 |
| ドライバー | リーダーメーカーの PC/SC ドライバー、および Windows の Smart Card サービスが実行中であること。 |
| 表示 | Microsoft Edge WebView2 ランタイム、または インストール済みの Google Chrome / Microsoft Edge / Chromium。 |
| Python（ソースから実行する場合のみ） | 3.11 以降。配布パッケージでは不要です。 |

## インストールと起動

**担当者の方:** 配布用の Windows パッケージをお使いください。`zairyu-reader.exe` を
ダブルクリックするだけです。それ以外の準備は不要です。

**ソースから実行する場合:**

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python tools\fetch_ocr_assets.py
python app.py
```

ブラウザーで `http://127.0.0.1:8787` を開きます。

`tools\fetch_ocr_assets.py` は、サイズの都合で Git 管理外としているローカルOCRモデルを
配置します。固定されたリビジョンをダウンロードし、リポジトリに含まれる
`resources/ocr/ppocrv6/manifest.json` と全ファイルのハッシュを照合してから配置します。
最初に1回だけ実行してください。

**インターネット接続が必要なのは、依存ライブラリのインストールとOCRモデルの取得時のみです。
カードの読み取りにインターネット接続は一切不要です。**

> **このサーバーを LAN・トンネル・リバースプロキシ・公開ホストに公開しないでください。**
> ローカルAPIは確認済みのカード情報を返しますが、利用者認証はありません。`--host` に指定
> できるのは `127.0.0.1`、`localhost`、`::1` のみで、それ以外は拒否されます。

詳細は [docs/installation.ja.md](docs/installation.ja.md) をご覧ください。

## Windows パッケージのビルド

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1
```

出力は `dist\zairyu-reader\zairyu-reader.exe` で、Python が入っていない Windows PC でも
動作するワンフォルダー構成です。ビルド時にOCRモデルとヘルス契約を検証し、テストを実行し、
スクリプトファイルが同梱されていないことを確認します。

詳細は [docs/building.ja.md](docs/building.ja.md) をご覧ください。

## 使い方

1. リーダーを接続し、アプリを起動します。
2. 使用するリーダーを選択して保存します。
3. 在留カードをリーダーの上に平らに置きます。
4. カード表面に印字された在留カード番号を入力します。
5. **読み取り開始** を押します。
6. **17項目すべてを手元のカードと照合します。** 特に氏名と住所を必ず確認してください。
7. 1件をコピーするか、複数件を一時リストに追加してまとめてコピーします。

一時リストは画面のメモリ上にのみ存在し、ページを閉じると消去されます。

> **クリップボードに関する注意。** コピーした内容は Windows のクリップボードに入ります。
> Windows のクリップボード履歴やクラウド同期に残る場合があります。「コピー内容を消去」は
> 現在のクリップボードの内容を置き換えますが、**Windows のクリップボード履歴は削除できません。**
> 共用PCではクリップボード履歴を無効にしてください。

コピー形式は1件あたり17行の固定 `ラベル<TAB>値` です。詳細は
[docs/copy-paste-format.md](docs/copy-paste-format.md)（英語）をご覧ください。

## 法令と同意について

カードの読み取りは、本人の同意がある場合、または確認する権限が別途認められている場合に
限って行ってください。在留カード情報の取り扱いには個人情報保護法が適用され、多くの職場では
所属組織の規程も適用されます。特定のカードを読み取る権限があるかどうかを本ツールが判断する
ことはありません。その責任は利用者にあります。
